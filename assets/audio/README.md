# Quiet Worlds

`quiet-worlds.mp3` is an original 80-second instrumental created for this
portfolio. It combines warm electric-piano chords, a soft melody, an ambient
pad, bass, and light percussion at 72 BPM, and loops at low volume.

The track is bundled locally: playback needs no streaming service or API key.
You may use and redistribute it with this portfolio.

To use a different song, replace the MP3 or update the source in each page's
`data-background-music` audio element. Only use a recording you have permission
to distribute. Set the initial volume in `assets/js/music.js` (currently 22%).
